# Модель погрешности сравнения фаз двух трёхфазных источников

Код и результаты моделирования к статье: Марков В. И. «Источники погрешности
контроля синфазности в системах резервного электропитания» (журнал
«Электрическое питание»).

Модель двухмодульного прибора: напряжение каждого источника измеряет свой модуль,
модули тактируются от общего генератора, моменты начала кадров фиксирует
аппаратный таймер контроллера, внешней опоры времени нет. Все числа —
результаты моделирования, эксперимента нет.

## Серии моделирования

| Серия | Условия | Испытаний |
|---|---|---|
| С1 | Проверка общим сигналом во всех условиях серий С2–С6 (сводка, своих испытаний нет) | — |
| С2 | Разность частот при номинальной частоте основного источника | 112 (28 значений Δf × 4) |
| С3 | Гармоники при равных частотах 50 Гц | 2000 |
| С4 | Несимметрия | 2000 |
| С5 | Неучтённая общая задержка d̄ | 441 (сетка 21 × 21 по d̄ и Δf) |
| С6 | Все факторы одновременно | 2000 |

## Как запустить

```
pip install numpy scipy matplotlib
python run_all.py            # всё: проверки, опорные числа, серии С1–С6, рисунки, сводка (около 1,5 ч на 2 ядрах)
python run_all.py --quick    # быстрая проверка установки (уменьшенные серии, несколько минут;
                             # пишет в results_quick/ и figures_quick/, полные результаты не трогает)
```

Отдельные части: `python checks.py`, `python check_reference.py`, `python check_literature.py`,
`python series.py C2 C3` (выбранные серии), `python c3_zc_tochnee.py`, `python figures.py`, `python summary.py`.
Время счёта серий — в `results/timing.json`.

Требуется Python 3.10+. Серии С1–С6 считались на Python 3.13 с NumPy 2 (точные версии того прогона не записаны). `causal_check.py` и рисунки выполнены на Python 3.14.8, NumPy 2.5.4, SciPy 1.18.1, Matplotlib 3.11.2; исходные варианты МНК в повторе С6 воспроизвелись побитово.

## Модель в кратком изложении

1. **Сигналы.** Фазные напряжения: прямая, обратная (K2U) и нулевая (K0U)
   последовательности основной гармоники и симметричные высшие гармоники с
   естественным чередованием; белый шум (70 дБ).
2. **Модули.** Отсчёты 8 кГц; сетка модуля смещена на δ ~ U(0; 125 мкс);
   задержка тракта d = d̄ + Δd, Δd ~ U(−20; 20) мкс; метка кадра с погрешностью ±2 нс.
3. **Калибровка.** Общий чистый сигнал 50 Гц на оба модуля; поправка
   c = Δφ̂/(2π·50 Гц) хранится как время и вычитается из меток модуля 2.
4. **Модель времени прибора.** Учитывает (или не учитывает) общую задержку d̄.
5. **Оцениватели** — см. `estimators.py`. Результат каждого относится к
   определённому моменту t_attr; погрешность ε = wrap(Δφ̂ − Δφ_ист(t_attr)).
   «К концу окна» — прибор выдаёт результат окна как текущий; «к середине» —
   результат снабжён меткой середины окна.

## Что модель не учитывает

Аналоговые тракты (делители, антиалиасные фильтры) представлены чистой
задержкой; нелинейность и квантование АЦП, температурный дрейф, межфазные
различия внутри модуля не моделируются. Сигналы стационарны: частота каждого
источника постоянна в пределах записи, качания частоты ДГУ и переходные
процессы не рассматриваются. Интергармоники отсутствуют.
